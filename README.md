Це бекенд для управління замовленнями, написаний на C# (.NET) у форматі Serverless на базі AWS

Фішка проекта в том, що тут немає ніяких вічно працюючих серверів або контейнерів, які жруть ресурси вхолосту. Архітектура побудована на хмарних сервісах: входящий HTTP-запит прилітає в API Gateway, моментально подхвачується AWS Lambda, дані замовлення зберігаються в S3-бакет, а при створенні нового замовлення в чергу SQS летить повідомлення. Ну і щоб це все можна було удобно потрогати і протестувати, я написав простенький і удобний консольний клієнт.

Стек
- C# / .NET — основна мова для лямбди і консольного застосунку.
- AWS Lambda — виконує всю логіку за запитом.
- Amazon API Gateway — приймає запити з зовнішнього світу.
- Amazon S3 — зберігає кожне замовлення у вигляді аккуратного JSON-файлу.
- Amazon SQS — відповідає за чергу повідомлень при створенні замовлень.

Мій развернутий ендпоінт, до якого стукає клієнт: https://4xzeli51pa.execute-api.eu-central-1.amazonaws.com
