Это бэкенд для управления заказами, написанный на C# (.NET) в формате Serverless на базе AWS 

Фишка проекта в том, что здесь нет никаких вечно работающих серверов или контейнеров, которые жрут ресурсы вхолостую.
Архитектура построена на облачных сервисах:
входящий HTTP-запрос прилетает в API Gateway, моментально подхватывается AWS Lambda, данные заказа сохраняются в S3-бакет, а при создании нового заказа в очередь SQS летит уведомление.
Ну и чтобы это всё можно было удобно потрогать и протестировать, я написал простенький и удобный консольный клиент.

Стек
* C# / .NET — основной язык для лямбды и консольного приложения.
* AWS Lambda — выполняет всю логику по запросу.
* Amazon API Gateway — принимает запросы из внешнего мира.
* Amazon S3 — хранит каждый заказ в виде аккуратного JSON-файла.
* Amazon SQS — отвечает за очередь сообщений при создании заказов.

Мой развернутый эндпоинт, к которому стучится клиент:
[https://4xzeli51pa.execute-api.eu-central-1.amazonaws.com](https://4xzeli51pa.execute-api.eu-central-1.amazonaws.com)
